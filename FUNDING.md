# Funding

Lingui is an open-source project maintained under the stewardship of [Crowdin](https://crowdin.com) and built by a community of contributors. The project doesn't collect donations and has no shared fund or treasury.

## Sponsoring Contributors

You can support individual Lingui contributors directly through GitHub Sponsors (preferred) or any other platform they list. Whether it's a maintainer, a frequent contributor, or someone whose work you appreciate, you're free to sponsor whomever you'd like.

Sponsorship helps contributors dedicate time to:

- Developing new features and improvements
- Fixing bugs and addressing issues
- Maintaining documentation
- Supporting the community

## Other Ways to Support

Financial support is not the only kind that matters. You can also:

- **Contribute code**: Submit pull requests for bug fixes, features, or documentation improvements
- **Help others**: Answer questions and help users in our [Discord community](https://discord.gg/hdNuF3rupQ)
- **Report issues**: File detailed bug reports or feature requests
- **Review pull requests**: Help review and provide feedback on open pull requests
- **Spread the word**: Share Lingui with others and write about your experiences

These contributions are recognized the same way code is - see our [Governance documentation](GOVERNANCE.md) for how contributors are nominated and acknowledged.
